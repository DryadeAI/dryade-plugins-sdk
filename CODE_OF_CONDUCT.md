# Code of Conduct

This project adopts the **Contributor Covenant 2.1** as its Code of Conduct, verbatim.

The canonical text is published at:

- **Web (recommended):** https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- **Plain markdown:** https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md

By participating in this project — submitting pull requests, filing issues, joining discussions, or interacting in the project's chat channels — you agree to abide by that document in its entirety.

## Reporting

To report a Code of Conduct violation, email **conduct@dryade.ai**. Reports are read by the project maintainers only and are kept confidential. We follow the Contributor Covenant 2.1 Enforcement Guidelines (linked from the canonical document above) when responding.

## Why we link instead of inlining

The Contributor Covenant has a fixed canonical URL maintained by its authors, and updates land at versioned paths (`/version/2/2/`, etc.). Linking — rather than inlining a copy that will silently drift from upstream — keeps this project bound to the authoritative source and makes future version bumps a single-line change here.
